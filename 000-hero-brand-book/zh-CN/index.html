01

核心观点

Hero 的存在，是为了在智能变得丰裕之后，重新定义人的价值。

02

1. 使命

Hero 帮助个人和组织在不放弃人的判断、目的与 Accountability 的前提下，创造非凡价值。

03

2. 愿景

让每一个有能力的人都可以成为 Hero：对价值负责，被能力放大，并通过学习持续增强。

04

3. 创始信念

智能正在变得丰裕。

责任并没有。

这会改变一切。

05

4. 核心哲学

Hero 从一个简单判断开始：

未来工作的边界，不再取决于组织能协调多少人。

而取决于一个承担 Accountability 的人，能够通过组合 Capability 创造多少价值。

Hero 不是把人降格为工具的操作者。Hero 让人拥有一个新的组织位置：价值的 accountable interpreter，能力的 orchestrator，以及后果的 owner。

HERO 四原则

HERO 由四项相互关联的原则组成。它们是一种品牌记忆结构，不是工作流程，也不替代 Hero Model。

字母 原则 含义
H 人的目的引领方向 人的目的与判断定义什么真正重要。
E 扩展能力放大人的影响力 通过组合 Capability，一个人能够创造超越个人能力边界的价值。
R 责任始终属于人 Execution 可以委托；Accountability 不可转移。
O 结果必须体现价值 价值必须在结果、证据、后果与学习中可见，而不只是产出。

字母顺序服务于记忆，不代表运行顺序。HERO 四原则说明 Hero 坚持什么；Hero Model 描述 Purpose、Responsibility、Capability、Value 与 Learning 构成的完整价值创造循环。

06

5. 品牌定义

Hero 是面向丰裕智能时代的哲学与出版体系。

HeroOS 是由 Hero 推导出的组织操作模型。

Hero Academy、Hero Method、Hero Lexicon 与 Hero Certification 是同一 Canon 的未来延伸。

07

6. Hero 一句话定义

Hero 是一个接受价值 Accountability，并组合 Capability 来实现价值的人。

08

7. Hero 是什么

Hero 是：

  • 一种关于人类 Accountability 的哲学；
  • 一套关于 Capability 放大价值创造的理论；
  • 一个官方出版 Canon；
  • 一种组织重构语言；
  • 一条让人变得更有能力、而不是更不像人的路径。
09

8. Hero 不是什么

Hero 不是：

  • 白皮书；
  • 咨询框架；
  • Agile、Scrum 或产品管理的替代品；
  • AI 自动化品牌；
  • 声称 AI 可以承担 Accountability；
  • 声称层级、团队或职能结构总是过时。
10

9. HeroOS 定义

HeroOS 是一个技术无关的组织操作模型。在 HeroOS 中，可识别的人类 Hero 接受 Value Commitment，通过合格的 Capability Unit 组合 Capability，以证据评估结果，并把每一次执行转化为 Organizational Memory。

11

10. 官方语言

Hero 的语言必须直接。

它应该像宣言，而不是咨询报告。

使用：

  • Execution is no longer the bottleneck.
  • Accountability is the new scarcity.
  • Capability can be delegated. Accountability cannot.
  • Every execution should make the organization more capable.

避免：

  • 模糊的转型话术；
  • 夸大的 AI 替代叙事；
  • 基于头衔定义 Hero；
  • 用工具定义 Capability；
  • 在行为没有改变时声称已经学习。

11. 核心术语

Term 品牌含义
Hero 价值创造中心承担 Accountability 的人
HERO 四原则 表达 Hero 坚持什么、但不替代 Hero Model 的四项品牌记忆原则
Accountability 对判断、价值和后果不可转移的负责关系
Capability 在明确条件下反复产生可验证结果的能力
Capability Unit 经过资格确认、可以实现 Capability 的执行单元
Value Commitment 对明确价值的 accountable promise
Organizational Memory 能改变未来行为的证据与判断
HeroOS 让 Hero 运作起来的操作模型

14. 设计语言

Hero 设计使用：

  • 黑；
  • 白；
  • Hero Red；
  • 大量留白；
  • 强排版；
  • 简单线稿图；
  • 一页一个观点。

Hero 设计避免：

  • 渐变；
  • 装饰性复杂度；
  • 过载图示；
  • 密集咨询幻灯片；
  • 削弱核心句子的视觉噪音。
16

15. Hero Red

Hero Red 是唯一强调色。

它用于表达 Accountability、后果、决策与勇气。

最终色值将在后续设计系统中批准；Founding Edition 只冻结 Hero Red 作为唯一官方强调色。
