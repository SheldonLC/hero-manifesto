# Contributing to The Hero Manifesto

The Hero Manifesto is a governed organizational declaration, not an uncurated collection of ideas. Contributions are welcome, but changes to Canon text require a clear rationale and deliberate review.

## Where to Contribute

- Start a GitHub Discussion for interpretation, organizational applications, new principle proposals, or substantial conceptual changes.
- Open an Issue for factual errors, broken links, accessibility defects, formatting problems, or translation corrections.
- Open a Pull Request only when an Issue or Discussion has established the intended change.

## Proposal Format

Include:

1. The current passage or publication area.
2. The problem the proposal addresses.
3. The proposed wording or behavior.
4. The organizational consequence of accepting it.
5. Any effect on the English source of truth or Chinese official translation.

## Canon Governance

- English is the source-of-truth language for the Founding Edition.
- Chinese is the official Simplified Chinese translation.
- Translation corrections must preserve meaning, not merely literal wording.
- Changes to principles, definitions, promises, or official language require owner approval.
- Publication and license status must not be changed implicitly through a contribution.

## Conduct

Challenge ideas directly and respectfully. Explain tradeoffs, distinguish evidence from preference, and avoid personal attacks or promotional spam.
